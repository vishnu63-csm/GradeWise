Explain overfitting in Machine Learning and how to prevent it.
✦
Overfitting occurs when a machine learning model learns both the underlying pattern and noisy details of the training data so closely that it fails to generalize to new unseen test data.

Key Prevention Techniques:
  • Cross-Validation: Use k-fold cross-validation to evaluate model performance across multiple splits.
  • Regularization (L1 / L2): Penalize large feature weights (`Lasso` / `Ridge`).
  • Early Stopping: Halt training when validation loss begins to rise.
